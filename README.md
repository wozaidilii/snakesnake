# 老母鸡 Henyard

一只白母鸡带着黄小鸡走谷场的原创解谜。T3 栈：Next.js、tRPC、Tailwind、Prisma（SQLite）。

啄下去的谷会从队尾排出来。玉米会叫来一只黄小鸡。木桶和队伍都能压住踏板。水渠只送木桶。蛋要送回鸡窝，泥坑会把蛋磕破。从向日葵上离开会被弹出去。栅门合上时会剪断卡在门里的那一节。篱剪可以把一只母鸡分成两只。

关卡、画面和声音都是原创的。变长、推箱子、分身这些玩法来自公开的解谜设计，不是某一款游戏的素材或关卡复刻。

```bash
pnpm db:push
pnpm dev
pnpm test
```

方向键或 WASD 移动，Z 撤销，R 重来，空格剪开，Tab 换母鸡，G 哼一声。进度写在本地，并同步到 SQLite。
