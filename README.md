# 咕咕归巢 · Henyard

温暖的像素农场解谜。带着小鸡收集蓝李、推动果箱开门、照顾鸡蛋，最后回到小屋。六个章节、40 个原创关卡（8 个教学，32 道正式谜题，其中 4 道为选修挑战），所有关卡可自由选择，没有倒计时。

## 启动

```bash
npm install
npm run db:push
npm run dev
```

已有依赖时直接运行 `npm run dev`。Prisma 使用标准 `@prisma/client` 输出，安装后的 `postinstall` 会生成客户端；数据库结构与旧存档不变。

```bash
npm test                  # 引擎、40 关回放、最短步数、关键机制不可绕过
npm run typecheck
npm run validate:levels    # 输出 output/qa/campaign-report.json
npm run gen:pars           # 重新计算主线最短步数，所有关卡成功才写文件
npm run build
npm start
```

主界面以放大的棋盘为中心。选关、收藏、规则与逐层提示按需打开；正式关不会在开局展示解题要点。

## 操作与规则

- 方向键 / WASD / 屏幕方向按钮 / 在棋盘滑动：每次移动一格。快速连续输入最多缓存下一方向；长按不会失控连走；撤销、重来、换关、换队、打开弹窗和窗口失焦都会清掉缓存。
- 领队只能前进或侧转，不能直接掉头，独自行动或只带一只小鸡时也一样。脚下箭头显示朝向，反向按钮划线；撞墙不改变朝向、不耗步数。转回身后需要实际绕行空间，走错仍可撤销。
- Z：无限撤销。R：重来，重来也可以撤销。
- F 或点选育芽地上发光的小鸡：离群长大。该小鸡成为新领队，带走身后的伙伴，不减少总成员；每块育芽地只能用一次，动作可撤销。
- Q 或点选另一只母鸡：切换队伍。Tab 保持正常的键盘焦点导航。
- 蓝李必须全部收集；麦穗增加一只小鸡；草帽是可选纪念。
- 母鸡、小鸡和果箱都能压住陶土踏板。果箱只能推；水渠会顺箭头运送果箱。
- 普通门需要踏板；母鸡踩入风铃会切换同记号的铃铛门，小鸡经过不触发，离开后保持开关状态。两类门各自独立。同类栅门在任意一扇门被伙伴占据时保持开启，可以利用并排门接力；不会切断鸡群。
- 荷叶桥在最后一只鸟或果箱离开后收起成水，绝不把伙伴丢下去。撤销连同桥面一起恢复。
- 每章主线完成后收藏纪念物；选修题和最短路线不阻挡推进，提示不扣奖励。地图有推荐路线，手记保留六章纪念和路边草帽。
- 一次携带一枚蛋，送到标有「蛋」的编篮；已经填满的编篮不再接收蛋。带蛋走进泥塘会失败，可以撤销。
- 完成收集和送蛋后，带队的 1 号母鸡进入标有「回家」的小屋通关。新领队可以独立行动、运蛋、推箱和留门。只有 1 号触发通关。

## 项目结构

- `src/game/campaign.ts`：40 个原创手工棋盘、设计意图、三层提示。
- `src/game/progression.ts`：主线推荐、选修分流、章节纪念和最短路线统计。
- `src/game/engine.ts`：纯状态转换；旧规则通过默认状态保留，新主线使用 `gentle` 和 `noReverse` 规则。
- `src/game/solver.ts`：离线广度优先求解器，输出最短路径；区分协作母鸡的身份与朝向，不进入玩家操作循环。
- `src/app/_components/game-app.tsx`：游戏、章节、地图、提示、音效设置、存档。
- `src/app/_components/board.tsx`：响应式棋盘与侧身鸡群行走、成长动画、果箱沿水渠路径漂流和事件反馈。
- `src/app/_components/sprite.tsx`、`public/art/farm-atlas-v2.png`、`public/art/farm-expansion-v3.png`：像素素材及独立裁切视窗。
- `docs/level-design.md`：设计依据与章节节奏。
- `public/art/README.md`：素材来源和完整生成提示词。

旧的 `baked-levels.ts`、`twists.ts`、`generate.ts` 留作历史实验，不再进入主线。`npm run gen:legacy` 只生成旧实验素材；新关卡应手工编辑并运行验证。

旧存档键 `loamly-dig-v1` 保留。不能直接掉头改变了全部关卡的合法路线，因此本版 40 关统一使用 `flock-01-r3` 至 `flock-40-r3`，重新计算最短步数；17 道棋盘同步修改地形。旧成绩保留在存档中，不计作新规则通关；旧的最近选择会定位到对应新版。显示编号与稳定 ID 分开，重排顺序不改变记录。通关与最佳步数保存在浏览器并同步 SQLite；网络失败时仍可游玩与本机保存。重新加载会返回上次选择的关卡起点，不恢复进行中的步数。
