# 壤虫 Loamly

一条往下挖的原创解谜。T3 栈：Next.js、tRPC、Tailwind、Prisma（SQLite）。

吃下去的土会从身后排出来。红苹果让身体变长。石头和身体都能压住按钮。水流只运石头。蛋要送回巢，裂缝会把蛋磕破。从雏菊上离开会被弹出去。滑门合上时会剪断卡在门里的那一节。剪刀可以把一条虫分成两条。

关卡、画面和声音都是原创的。地底蠕虫、推箱子、分身这些玩法来自公开的解谜设计，不是某一款游戏的素材或关卡复刻。

```bash
pnpm db:push
pnpm dev
pnpm test
```

方向键或 WASD 移动，Z 撤销，R 重来，空格剪开，Tab 换虫，G 哼一声。进度写在本地，并同步到 SQLite。
