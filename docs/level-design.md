# 关卡与体验设计 · 离群成长版

## 设计目标

采用温暖的田园像素风，但建立独立的角色与道具设计：麦色母鸡、青绿围巾、蓝紫果实、果箱、布衬编篮、太阳/月亮陶土踏板和青瓦小屋。参考图仅作为风格方向，游戏没有使用截图里的素材。

规则围绕“伙伴的位置和数量也是解谜资源”展开。只保留 01–04 与 19 共五个教学关；其余十九关必须有实质的站位、顺序、队长分工或长度选择。

## 参考与转化

- **Braid / The Witness**：Jonathan Blow 的 NYU Game Center 访谈强调谜题应有明确存在理由，并给予与投入相称的发现。这里据此用一个可描述的认知变化作为每关目的。来源：https://gamecenter.nyu.edu/game-designers-in-detail-jonathan-blow/
- **Baba Is You**：Arvi Teikari 的创作者访谈讨论从规则互动倒推谜题，以及删除绕过目标互动的解法。这里将其转化为逐关的关键机制禁用检查。来源：https://www.gamedeveloper.com/design/designing-i-baba-is-you-i-s-delightfully-innovative-rule-writing-system
- **推箱子式空间规划**：本项目应用“只能推，不能拉”和推箱站位约束；布局独立设计，未复制现成题目。

这些是设计原则的转化，不是上述游戏关卡的复刻，也不把最短步数或求解器搜索量当成人类难度的评分。

## 离群长大

地图上的 `S` 在新主线中是一次性的育芽地。只有小鸡可以在这里长大，母鸡站在上面不会触发。按 F 默认选择当前队伍第一个符合条件的小鸡；若有多个候选，也能直接点选。

分队时，前半队保留原领队、编号和携带的鸡蛋；育芽地上的小鸡成为新领队，带走后半队，立即切换到它。成员总数守恒，地块变为已使用。撤销会连同地块、队伍编号、携蛋状态一起恢复。Q 或点母鸡换队，只有 1 号可结束本关。

长队能借尾随小鸡跨过远处踏板和门的间距；短队能在死胡同取物后掉头。两扇同色门可以利用占门规则进行接力。旧版剪断逻辑仅为历史引擎保留，新主线不删除鸡群成员。

## 章节与实际规划点

| 范围 | 核心任务 | 代表关卡 |
| --- | --- | --- |
| 01–04 | 跟随、推箱、运蛋、离群的明确教学 | 04 第一次离群 |
| 05–06 | 先背离目标推箱，再绕障碍归位 | 05 先退，再进；06 绕过自己的目标 |
| 07–12 | 双门交接、麦穗数量、分队长度、长队过门后缩短 | 07 门里的接力；11 长大之后的转身；12 抱蛋的接力赛 |
| 13–18 | 搬箱站位与携蛋路径叠加，先安顿再取物 | 14 近处的远路；16 窄巷里的珍宝；18 小院的调度员 |
| 19 | 唯一的水流规则教学 | 19 溪水邮差 |
| 20–24 | 落岸后重新找推箱站位、双箱分工、运蛋与水路组合 | 20 接住下游；23 干路与水路；24 归巢之前 |

地图明确标记“教学 / 巧思 / 进阶 / 烧脑 / 挑战”，各关自由选择。五个教学最短 11–16 步，正式谜题最短 13–39 步。第 11 关虽短，仍必须先增长才能过门，随后分队才能从死胡同返回。不能用延长步行距离替代认知难度。

## 防止退化成机械题

- 24 关全量 BFS 求最短解并逐步回放，包含可选草帽路线。
- 31 项关键机制检查：分别禁止推箱、成长、离群或水运后，要求穷尽搜索并得到无解。达到预算不能算通过。
- 05、06、14、20、23 的最短解必须至少推箱四次，涉及至少三个推动方向，防止退化成顺手直推。
- 07 的最短解必须多次交换队伍，不能只把帮手停到踏板上就结束。
- 独立测试成长守恒、携蛋归属、地块消耗、多候选选择、不可变历史以及弯渠完整运动路径。

完整答案、机制检查与动作统计见 `output/qa/campaign-report.json`。这些检查证明规则和约束成立；“有趣”和玩家实际难度仍需真实试玩来校准。

## 操作与反馈

- 一次一格，移动动画期间缓存至多下一方向。重复长按不自动失控连走。
- 撤销、重来、换队、换关、弹窗与失焦清除输入缓存；重来也可撤销。
- 滑动从空地或母鸡身上都有效；轻点才执行换队或成长。
- 145 ms 行走起伏，成长放大反馈，果箱沿真实水路拐弯漂流，最长 520 ms；收获和送蛋有短提示。
- 可成长小鸡有发光轮廓与 F 标记，新领队有编号与色调区别。
- 门、踏板使用太阳/月亮双重标记，除了颜色也可按形状识别。
- 小屏移动和工具按钮至少 44 px，320 px 宽时工具单独成行。
- 支持静音及系统减少动态效果设置，无倒计时、无限撤销、三层提示。

新关卡使用 `flock-*` ID，旧成绩保留但不被误记为新版通关。
